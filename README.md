# Shopping Skill

帮你决定买什么、为什么值得买、哪些不值得买。适用于全新和二手商品。

从用途出发筛选候选，调查型号的已知问题，再核对具体商品的配置、价格和状态。比较时说明便宜一档牺牲什么、贵一档增加什么，也可以建议等待或不买。

## 工作方式

理解需求 → 定标准 → 搜候选 → 查型号问题 → 验证具体商品 → 给建议。

- 只问影响选择的缺失信息，提问后继续不依赖答案的研究。
- 标准随品类和用途变化，不套固定参数清单。
- 横评展示主要候选、型号问题和排除理由，结论先行。
- 有站点配方时，优先从页面接口取列表，在脚本里精简数据；具体商品仍打开详情核对。

## 安装

下载本仓库，将 `SKILL.md` 和整个 `references/` 文件夹放到 Codex 的 `skills/shopping/` 目录：

```text
~/.codex/skills/shopping/
├── SKILL.md
└── references/
    ├── cdp-interface.md
    └── sites/
        ├── 闲鱼.md
        └── 京东.md
```

Windows 默认 `%USERPROFILE%\.codex\skills\shopping`；设了 `CODEX_HOME` 则用其下的 `skills\shopping`。

不要只复制 `SKILL.md`，站点配方也需要一起安装。重新加载 Codex 后，在新聊天中使用。

## 使用

直接描述需求，也可以用 `$shopping` 明确调用：

```text
$shopping 帮我找4000以下用于打CS2的二手游戏本，闲鱼买。
```

```text
$shopping 300元左右买个通勤用的无线降噪耳机，优先京东。
```

```text
$shopping 帮我比较这两个商品链接，哪个更值？
```

可以补充预算是否严格、用途、购买平台、新旧要求，或直接提供商品链接。

## 站点与工具

使用 Agent 现有的搜索、浏览工具，不需要额外安装爬虫或服务。接口取数需要浏览器提供 CDP 能力；没有该能力时使用普通搜索浏览。

| 站点 | 配方与实测范围 |
| --- | --- |
| 闲鱼 | [配方](references/sites/闲鱼.md)：已验证登录后的列表接口与价格解析，需要登录。 |
| 京东 | [配方](references/sites/京东.md)：已验证登录后的30条列表、商品详情与配置切换；未验证翻页和结算。 |
| 淘宝、拼多多 | 暂无配方。2026-10-11 本次 Codex 浏览器测试被站点安全策略拦截，未完成采集验证。 |

配方是取数方法，不是平台可用性的保证。登录状态、页面变化和浏览器工具权限都会影响实际访问；没有配方的站点，在工具允许访问时照常浏览。
