- **站点**：`https://mobile.yangkeduo.com/`，首页搜索框可搜索；实测搜索页 `/search_result.html?search_key=<编码关键词>&search_type=goods`。商品链接用详情当前 URL 中的 `goods_id`，输出为 `https://mobile.yangkeduo.com/goods.html?goods_id=<id>`，不带账号和追踪参数。

## DOM 精简列表

先读当前搜索页确认卡片结构，再在浏览器脚本内解析，只输出精简字段。以下选择器是本次页面的实测值，类名可能变化；匹配为空时重新检查一张卡片的 DOM，不把空结果当作没有商品。

```js
const rows = await tab.playwright.evaluate(() =>
  Array.from(document.querySelectorAll('div._3glhOBhU[data-uniqid]'))
    .map(card => {
      const title = card.querySelector('div._3ANzdjkc')?.textContent?.trim();
      const priceText = card.querySelector('span._3_U04GgA')
        ?.textContent?.replace(/\s/g, '');
      const amount = priceText?.match(/¥([\d.]+)/)?.[1];
      const text = card.innerText;
      return {
        cardKey: card.getAttribute('data-uniqid'),
        title,
        displayPrice: amount ? Number(amount) : null,
        priceLabel: text.includes('券后') ? '券后' : null,
        summary: text.replace(title || '', '').replace(/\s+/g, ' ').trim()
      };
    }).filter(row => row.title)
);
// 原始页面留在脚本内；只输出本次需要的 rows，并记录抓取时间。
```

- `cardKey` 是当前渲染卡片标记，**不是 goods_id，也不能跨重载复用**；列表没有暴露的商品 ID、店铺名或 SKU 不要补造。
- 点击前重新提取目标卡片，核对标题和价格，使用当前整张卡片定位器，例如 `tab.playwright.locator('div._3glhOBhU[data-uniqid="84"]').click()`。本次只点标题曾进入其他商品，整张卡片点击核验成功；不能据此认定站点存在固定跳转故障。
- 跳转后核对详情标题和品牌，再记录 URL 的 `goods_id`。身份不匹配则不把该详情价格归给原候选。
- 滚动加载后按当前 DOM 提取；本次只验证首批 20 张卡片，未验证分页、完整列表覆盖或跨批 ID 去重。

## 详情与 SKU 核验

详情的通用参数可能混合不同配置，价格和配置以规格面板的「已选」文本为准。打开底部购买入口后先观察：本次「发起拼单」只打开 SKU `dialog`，其中「确定」尚未点击；其他页面若进入结算，按实际状态处理，不把按钮名称当作固定流程。

在面板内选目标配置，读取 `tab.playwright.getByRole('dialog').innerText()`，记录已选容量、材质、功率、套餐及对应价格。**只核验到 SKU，不点击确定或提交订单。** 本次选择配置后 `goods_id` 未变，不能只靠 URL 判断规格。

列表的券后价、详情补贴价和单独购买价分开记录；已显示的补贴不重复扣减，优惠条件和运费未核对时不称为结算到手价。详情店铺保障与商品评价也分开：本次商品页含「该商品所属店铺评价」，不可冒充该 SKU 的评价。
