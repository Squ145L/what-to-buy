# 京东（实测 2026-10-11）

- **站点**：搜索页 `https://search.jd.com/Search?keyword=<编码后的关键词>&enc=utf-8`；商品页 `https://item.jd.com/<skuId>.html`。
- **登录**：本次未登录访问搜索页跳转到 `passport.jd.com`；用户扫码登录后返回搜索结果。遇到登录页先请用户登录，不把跳转当成空结果。

## 列表接口

按 `references/cdp-interface.md` 捕获页面真实请求，不自行拼签名或复制登录凭据。

- 接口：`https://api.m.jd.com/api`，URL 查询参数 **`functionId=pc_search_searchWare`**。同一路径还有其他业务接口，不能仅按 pathname 匹配；忽略 `Preflight`。
- 响应 `code === 0`，商品数组为 **`data.wareList`**；本次一批 30 条，响应 402,236 字符。原始响应留在脚本变量里。
- 页码和批量大小见 `data.pageInfo`。本次接口 `pageCount=200`、页面显示 100 页，翻页按实际页面控件，不凭接口页数推定可访问范围。

解析示例（`body` 为本次捕获的响应体）：

```js
const response = JSON.parse(body);
if (response.code !== 0 || !Array.isArray(response.data?.wareList)) {
  throw new Error('未取得京东商品列表');
}
const rows = response.data.wareList.map(w => ({
  skuId: String(w.skuId),
  title: (w.wareName || '').replace(/<[^>]*>/g, ''),
  shop: w.shopName,
  jdPrice: w.jdPrice,
  estimatedPrice: w.finalPrice?.estimatedPrice ?? null,
  priceLabel: w.finalPrice?.title ?? null,
  governmentSubsidy: w.govSubsidyBenefit,
  platformSubsidy: w.subsidyPrice,
  firstPurchase: w.cashFirst,
  coupons: w.couponInfo,
  isAd: w.isAdv === 1,
  badges: (w.iconList1 || []).map(i => ({text: i.text, label: i.label})),
  url: `https://item.jd.com/${w.skuId}.html`
}));
// 只输出 rows 中本次比较需要的字段，同时注明抓取时间。
```

## 价格与详情核对

- `jdPrice` 与 `finalPrice.estimatedPrice` 分开保留；后者可能标为「到手价」「国补领后价」，也可能为 null。`subsidyPrice` 是补贴信息，不是整机售价；不要重复扣减。
- 优惠与账号、配送地区、领券条件有关。列表中的估算价不等于结算实付价；打开详情核对价格标签与优惠组成，不默认用户符合国补或首购条件。
- 本次 DOM 商品卡片带 `[data-sku]`，可用于同一批接口数据的 SKU／价格核对。某些卡片隐藏 `jdPrice` 或不显示价格标签，不要求每个字段都在页面出现。
- 打开具体 SKU 后核对选中配置、店铺、自营标识、配送及售后；切换配置可能更换 URL 中的 SKU。等新标题与价格加载后再记录，不能沿用原 SKU 的价格。
- **「京东物流」不等于「自营」**：本次 `iconList1` 中「京东物流」为 `label=jdwl`，提示商家提供售后；「自营」为 `label=zy`。以详情页实际服务说明为准。
- 评价可能混合不同配置；本次 RTX5060 商品页出现了 RTX5070Ti 的评价，引用前核对对应版本。
